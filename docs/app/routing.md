# Маршрутизация

[← BackupPC VPN](README.md)

Режим выбирается на экране **Подключение**.

| Режим | Что идёт через VPN |
|---|---|
| **Умная маршрутизация** (рекомендуется) | Всё, кроме локальной сети и сайтов, доступных напрямую в вашем регионе (по базам geosite/geoip). |
| **Всё через VPN** | Весь интернет-трафик, кроме обязательных системных исключений. |
| **Своя маршрутизация** | По вашим правилам, в заданном порядке: домены, IP/подсети, geosite/geoip, приложения. Для сложных случаев есть редактор правил в JSON. |
| **Экспертный режим** | Полная конфигурация Xray (Raw JSON). Узлы `protocol: backuppc` обрабатывает ядро приложения. |

Базы geosite/geoip берутся из
[v2fly/domain-list-community](https://github.com/v2fly/domain-list-community)
и [v2fly/geoip](https://github.com/v2fly/geoip); обновляются вручную в
**Расширенные → Xray → Данные маршрутизации (Geodata)** или по интервалу в
**Расширенные → Xray → Автообновление**.

Формат правил и полей Xray: документация
[Xray-core](https://xtls.github.io/config/routing.html).
