# BackupPC VPN

[Маршрутизация](routing.md) · [Конфиденциальность](privacy.md) · [Благодарности](credits.md)

BackupPC VPN — клиент для серверов xray-backuppc. Трафик идёт по протоколу
`backuppc`: VLESS поверх gRPC/HTTP2 + TLS, внешне похожий на поток
резервного копирования BackupPC. Приложение построено на
[OneXray](https://github.com/OneXray/OneXray) и распространяется под той же
лицензией GPL-3.0.

Приложение не предоставляет серверов: нужна ссылка от администратора
вашего сервера.

## Подключение

1. **Серверы → Добавить серверы → Импорт ссылок.** Вставьте ссылку
   `backuppc://…` (одна ссылка в строке; подписки и обычные ссылки
   `vless://`, `vmess://`, `trojan://`, `ss://` тоже поддерживаются).
2. **Подключение** — выберите сервер или «автоматически» и нажмите кнопку
   подключения. Android один раз попросит разрешение на VPN.
3. Значок щита в строке состояния означает, что туннель поднят. Для
   быстрого включения можно добавить плитку «BackupPC VPN» в шторку.

## Настройки туннеля (Android)

**Расширенные → Туннель VPN:**

- **Системный VPN Android** — адрес TUN и приложения, которые идут через VPN:
  все, только выбранные или все, кроме выбранных;
- **DNS туннеля**;
- **Исходящий интерфейс Xray**.

DNS через сервер `backuppc` идёт по TCP: протокол не переносит UDP.

## Ссылки «поделиться»

Приложение делится серверами и настройками ссылками вида
`backuppcvpn://app/config/add?…`; их можно вставить в «Импорт ссылок» или
открыть на устройстве с установленным BackupPC VPN.
