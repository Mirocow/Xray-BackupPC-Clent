# Конфиденциальность

[← BackupPC VPN](README.md)

BackupPC VPN не собирает и не отправляет разработчикам никаких данных: в
приложении нет аналитики, рекламы и отчётов о сбоях.

Серверы, подписки и настройки хранятся только на устройстве. Резервную
копию конфигурации создаёте вы сами, и она остаётся там, куда вы её
сохранили.

## Какие сетевые запросы делает приложение

- **Ваш VPN-сервер** — весь трафик туннеля.
- **Подписки** — запросы на адреса подписок, которые вы добавили. Если в
  подписке включён HWID, провайдеру подписки передаётся идентификатор
  устройства.
- **Определение региона при первой настройке** — один запрос к
  `ip-check-perf.radar.cloudflare.com` напрямую, мимо VPN; ответ не
  сохраняется.
- **Проверка задержки** — запросы к `cp.cloudflare.com` или
  `www.google.com/generate_204` (выбирается в настройках) через сервер.
- **Базы маршрутизации** — загрузка geosite/geoip с GitHub (v2fly) при
  ручном обновлении или по интервалу автообновления.

Проверки обновлений в приложении нет.

## Разрешения Android

- **VPN** — для работы туннеля;
- **уведомления** — состояние подключения;
- **камера** — только для сканирования QR-кода с сервером;
- **список приложений** — только для выбора приложений, которые идут через
  VPN или мимо него.
