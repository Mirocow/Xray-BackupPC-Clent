# backuppc — Backup-Emulator client (outbound, SOCKS5)

Клиентская половина транспортного плагина «Backup-Emulator»: локальный
**SOCKS5**-прокси, выталкивающий трафик через VLESS-туннель, замаскированный
под **поток периодических бекапов BackupPC** (rsync-агент, грузящий чанки
на узел хранения). Несущий канал — **gRPC over HTTP/2 + TLS**.

Модуль Go без сторонних зависимостей (только stdlib). Спецификация
протокола — [backup.proto](backup.proto); сервер — репозиторий
`xray-backuppc`.

```
 приложения                    клиент                        сервер
┌───────────┐  SOCKS5   ┌──────────────────────┐  gRPC/h2  ┌──────────┐
│ браузер и │ ────────> │ VLESS → кадры ТЗ с    │ ────────> │ VLESS →  │
│ т.п.      │           │ случайным паддингом, │  TLS      │ TCP-цели │
└───────────┘           │ пинги 20±15 c,        │           └──────────┘
                        │ псевдо-бэкапы 16–120 КиБ
└───────────┘           └──────────────────────┘
```

## Сборка и запуск

Требуется Go ≥ 1.22.

```bash
cd backuppc
go build -o backuppc-client ./cmd/backuppc-client
cp config.example.json config.json    # адрес сервера и uuid
./backuppc-client -config config.json
```

Проверка:

```bash
curl --proxy socks5h://127.0.0.1:1080 http://example.com/
```

## Конфигурация

`config.json` (пример — `config.example.json`):

| Поле | Дефолт | Смысл |
|---|---|---|
| `serverAddr` | — | адрес Backup-Emulator сервера (host:port) |
| `uuid` | — | UUID VLESS-пользователя |
| `socksListen` | `127.0.0.1:1080` | локальный SOCKS5 |
| `host` | `lampa-tv.ru` | домен-донор (SNI/Host) |
| `insecure` | true | пропуск верификации TLS (только для тестов!) |
| `certFingerprint` | `""` | SHA-256 (hex) сертификата сервера — пиннинг |
| `endpointPaths` | 3 gRPC-метода | вызовы «узла хранения» (случайный выбор) |
| `backuppc.enabled` | true | эмуляция периодических бекапов |
| `backuppc.idleOnly` | true | псевдо-бэкапы только при простое ≥10 c |
| `backuppc.incrementalEvery` | 25m | интервал «инкрементов» (±40% джиттер) |
| `backuppc.fullEvery` | 8h | интервал «полных» (ночью 22–06) |

Остальные поля (паддинг, пинги, балансировка, ротация) — как на сервере,
см. README `xray-backuppc`.

## Эмуляция BackupPC

- идентификатор сессии — «задание»: `srv-fs-02.1174.6f3ac2b1`;
- User-Agent — случайный из пула `BackupPC-Agent/…`, `rsync-backup-client/…`;
- псевдо-задания: инкременты 2–8 МиБ каждые ~25 м, полные 32–128 МиБ
  ночью; каждое — всплески 16–120 КиБ с паузами 30–300 мс (padding-only
  кадры, прозрачные для VLESS);
- балансировщик плеч (ТЗ 3.3): при скачивании без аплоада доливается
  512 КиБ мусора;
- ротация чанков: 15–45 м (0.5–1.5× `maxSessionDuration`) или 2 GiB —
  каждое = новое TLS-рукопожатие и случайный gRPC-метод.

## Тесты

```bash
go test ./...   # кадры, gRPC-кодек, VLESS, планировщик BackupPC,
                # ротации (объем/время), эмуляция заданий, сквозной e2e
```

Библиотека протокола (`internal/backupemulator/`) идентична серверному
репозиторию `xray-backuppc` — файлы синхронизируются целиком, чтобы обе
стороны покрывались одними и теми же тестами контрактного поведения.
