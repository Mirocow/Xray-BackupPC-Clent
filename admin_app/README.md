# BackupPC Admin — Android-клиент управления сервером

Управление сервером **xray-backuppc** с телефона: дашборд, клиенты,
сессии и история завершенных, фильтр/DNS, TLS и журнал — всё, что умеет
REST Admin API панели (контракт — `docs/ADMIN-API.md` серверного
репозитория).

## Возможности

- **Подключение**: адрес панели (`http://…:8444` или https за reverse-proxy),
  токен администратора, опция «самоподписанный сертификат»; профиль
  хранится **только на устройстве** (SharedPreferences).
- **Дашборд**: скорости ↑/↓ в реальном времени, активные сессии,
  зонды, аптайм; CPU/RSS/куча Go/GC/горутины/fd — контроль того, что
  сервер «не течет» (рассчитан на годы без перезагрузки).
- **Клиенты**: список с live-скоростями и объемами (↑/↓ отдано/скачано,
  бейдж «в эфире»), добавление (UUID генерирует сервер), квота/срок/
  отключение, удаление, share-ссылка `backuppc://…` с копированием в
  буфер (импорт в OneXray на компьютере).
- **Сессии**: активные (kill в один тап) и «Недавно завершенные» с
  причинами (`upstream-closed`, `blocked:ads`, `idle-timeout`…).
- **Фильтр и DNS**: тумблеры фильтра и торрентов, обновление списков
  из источников, свои домены, статистика/последние блокировки,
  редактирование DNS-апстримов, топ доменов.
- **Ещё**: TLS-статус (реальный/самоподписанный, сроки, отпечаток
  с копированием, перечитать файлы certbot), список несущих методов
  сервера, журнал, выход/забыть профиль.

Приложение ничего не знает о VPN-туннеле — это чистый менеджер:
весь трафик идет к REST-порту панели (по умолчанию `8444`).

## Сборка APK

Требуется Flutter SDK (те же версии, что и основной клиент OneXray —
Dart SDK ≥ 3.13). В этом каталоге (`admin_app/`):

```bash
# 1. сгенерировать платформенные папки (lib/ и pubspec не тронет)
flutter create . --project-name backuppc_admin --platforms android --org com.example

# 2. зависимости
flutter pub get

# 3. запустить на подключенном телефоне / эмуляторе
flutter run

# 4. релизный APK (arm64 + arm32 + x64 в одном)
flutter build apk --release
# только под современный телефон (легче):
flutter build apk --release --target-platform android-arm64
```

Готовый файл: `build/app/outputs/flutter-release/app-release.apk`.
Установить на телефон (разрешить «неизвестные источники»).

Для публикации в сторе: `flutter build appbundle --release` + подпись
(`key.properties` по документации Flutter).

## Структура

```
lib/
  main.dart            — вход, тема (тёмная ops), общий каркас
  ui.dart              — цвета/карточки в стиле веб-панели
  api/api.dart         — REST-клиент (dart:io HttpClient, Bearer-токен,
                          опция self-signed TLS)
  api/models.dart      — DTO Admin API (устойчивы к старым версиям сервера)
  state/app_state.dart — подключение/логаут, сохранение профиля
  pages/               — login, home (табы), dashboard, clients,
                          sessions, filter+dns, more (TLS/журнал)
```

## Совместимость

- Сервер **1.4.0+** — все функции (включая метрики Go-рантайма).
- Сервер **1.3.x** — всё, кроме метрик кучи Go (карточка покажет 0).
- Сервер **1.2.x** — базовые метрики; история/фильтр/DNS/TLS-страницы
  покажут пустые данные (приложение честно предупреждает о старой
  версии на дашборде).

## Безопасность

- Токен хранится в SharedPreferences (не в внешнем хранилище);
  утечка токена = полный доступ к панели — храните телефон под
  блокировкой, для чужих телефодов используйте отдельный профиль
  без «Запомнить».
- Панель сервера слушает HTTP — на публичном адресе используйте
  https reverse-proxy (nginx/caddy) и открывайте приложение по https.
- Ротация токена (`POST /api/token/rotate`) мгновенно отзывает
  сохраненный на телефоне профиль.
